## Hướng dẫn minh chứng Lab 8 (`docs/evidence/lab-08/`)

1. **Yêu cầu của môn học:** Ảnh chụp lịch sử commit trên giao diện web của repository GitHub (`https://github.com/thpdun/KTS-Class-Fund/commits/main`), thể hiện rõ:
   - Commit với thông điệp chính xác: `lab-08: khoi tao codebase nhom va dac ta v0.1`.
   - Có sự tham gia / đóng góp của các thành viên trong nhóm.
2. **Quy tắc trung thực học thuật:**
   - Tuyệt đối không tạo ảnh giả, không dùng ảnh của nhóm khác.
   - File ảnh minh chứng sẽ được thành viên nhóm chụp và lưu vào đây sau khi thực hiện lệnh `git push` lên GitHub.
